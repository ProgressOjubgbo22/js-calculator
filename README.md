🧮 iPhone-Style JavaScript Calculator

A sleek and fully functional iPhone-inspired calculator built with HTML, CSS, and JavaScript.
It performs basic arithmetic operations and includes features like percentage, sign toggle, and delete — all in a clean, modern interface.

🚀 Live Demo

🔗 View Demo
 https://github.com/ProgressOjubgbo22/js-calculator

🎯 Features

Perform Addition, Subtraction, Multiplication, and Division

Includes AC (All Clear), Delete (⌫), % (Percent), and +/- (Toggle Sign)

Real-time display that shows the full expression

Smooth button animations and user-friendly layout

Handles invalid operations like divide-by-zero gracefully

🧠 What I Learned

DOM manipulation and event handling in JavaScript

Handling multiple operators and states in calculator logic

Building responsive layouts using Flexbox and CSS Grid

Writing clean, modular, and readable JavaScript
